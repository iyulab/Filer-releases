# Filer — Downloads

Filer is a desktop file explorer with AI capabilities.

## Download

**Latest stable release:**

[Download for Windows](https://github.com/iyulab/Filer-releases/releases/latest)

## System Requirements

- Windows 10/11 (x64)
- No additional runtime installation required

## Installation

1. Download `filer-x.x.x-setup.exe` from the latest release
2. Run the installer (no admin required, installs per-user)
3. Launch Filer from Start Menu or Desktop shortcut

## Auto-Update

Filer checks for updates automatically on startup.
Updates are downloaded in the background and applied on restart.

## Update Channels

- **Stable** (default): production-ready releases
- **Beta**: preview releases (opt-in via Settings)
